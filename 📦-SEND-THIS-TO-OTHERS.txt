==================================================
  STUDENT COUNCIL VOTING SYSTEM
  Installation Instructions
==================================================

STEP 1: Install Node.js (One-time only)
----------------------------------------
Go to: https://nodejs.org/
Download the LTS version
Install it (click Next on everything)
Restart your computer


STEP 2: Run the System
----------------------------------------
Double-click the file:
   INSTALL-AND-RUN.bat

Wait for 2 PowerShell windows to open.
First time takes 1-2 minutes to install packages.


STEP 3: Open in Browser
----------------------------------------
Go to: http://localhost:5173


THAT'S IT! The system is now running on your computer.

==================================================
  TO STOP THE SYSTEM
==================================================

Close both PowerShell windows that opened.


==================================================
  TO RESTART LATER
==================================================

Double-click: START-SERVERS.bat
(No installation needed after first time)
